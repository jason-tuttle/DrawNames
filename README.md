# Rand-O-mizer

### Inspired by a sibling gift exchange

A random collection of random things for randomizing:
- 🎩 Draw names "from a hat" for gift exchanges!
- 🎲 Roll any number of dice for board games or dice games like Yahtzee
- 🌀Spinners for board games: set how high the spinner goes!
- **Coming soon**: ⏳ a physics-based sand timer for games like Pictionary or charades!
